# 📝 悬浮待办 (Float Todo)

一款运行在 Windows 桌面上的悬浮待办应用，像 QQ 侧边栏一样可以收缩/弹出，界面美观，功能完整。

---

## ✨ 功能特性

### 核心功能
- **悬浮置顶** — 窗口始终显示在桌面最前方，不被其他窗口遮挡
- **边缘吸附隐藏** — 将窗口拖动到屏幕左/右边缘自动吸附，鼠标离开后自动收缩隐藏（只露出 4px 触发条）
- **鼠标触发弹出** — 鼠标移到边缘触发区域，窗口自动弹出
- **全局快捷键** — `Alt + T` 随时呼出/隐藏窗口
- **系统托盘** — 最小化到系统托盘，右键菜单快速操作

### 待办管理
- **添加/编辑/删除** 待办事项（双击任务可编辑）
- **优先级标记** — 🔴 紧急 / 🟡 重要 / 🟢 普通（左侧彩色条区分）
- **分类标签** — 💼 工作 / 🏠 生活 / 📚 学习 / 💪 健康 / 🔖 其他
- **截止日期** — 设置到期时间，过期任务醒目提示
- **完成打勾** — 已完成任务可折叠/一键清除
- **备注** — 每个任务可附加备注信息

### 外观定制
- **8 款预设主题** — 暗夜、午夜、森林、海洋、玫瑰、浅色、暖棕、磨砂
- **自定义背景色** — 颜色选择器自由选色
- **背景透明度** — 独立调节背景和窗口整体透明度
- **主题强调色** — 8 种预设 + 自定义颜色
- **窗口圆角** — 0~24px 自由调节

## 🚀 快速开始

### 环境要求
- Node.js 18+
- npm 8+

### 安装依赖
```bash
cd float-todo
npm install
```

### 开发模式运行
```bash
npm run dev
```
> 会同时启动 Vite 开发服务器和 Electron 窗口

### 仅预览 UI（浏览器）
```bash
npx vite
```
然后打开 http://localhost:5173

### 打包成 Windows 安装程序
```bash
npm run build
```
> 生成的安装包在 `dist-electron/` 目录

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt + T` | 呼出/隐藏窗口 |
| `Enter` | 提交待办输入 |
| `双击任务` | 进入编辑模式 |
| `Esc` | 取消编辑 |

```
float-todo/
├── electron/
│   ├── main.js          # Electron 主进程（窗口管理、托盘、IPC）
│   ├── preload.js       # 预加载脚本（安全桥接）
│   └── icon.png         # 托盘图标

│   ├── App.vue          # 主应用组件
│   ├── main.js          # Vue 入口
│   ├── style.css        # 全局样式
│   └── components/
│       ├── TodoItem.vue     # 单个待办项组件
│       ├── AddTodo.vue      # 添加待办组件

├── scripts/
│   └── start-electron.js  # 开发模式启动脚本
├── public/
├── index.html
├── vite.config.js
└── package.json
```

## 💾 数据存储

应用数据存储在系统用户目录：
- Windows: `%APPDATA%\float-todo\`
  - `todos.json` — 待办数据
  - `settings.json` — 应用设置
